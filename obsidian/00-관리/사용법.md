# 사용법 — 제2의 뇌 운용 규칙

> 이 볼트는 저장소가 아니라 **생각하는 도구**다. 규칙은 4개뿐이다.

---

## 흐름: 수집 → 정제 → 연결 → 복습

```
캡처(수시)      →  인박스에 던져넣기 (판단하지 않음)
정제(주 1회)    →  인박스에서 3~5개 골라 위키 노트로
연결(정제할 때)  →  새 노트에 링크 2개 이상 + MOC에 등록
복습(주 1회)    →  주간리뷰 템플릿으로 10분
```

## 규칙 1 — 수집은 무조건 인박스
떠오른 생각, 상담 단상, 설교 아이디어, 읽은 글 → 전부 `20-원자료/인박스/`.
분류 고민하지 않는다. 고민은 정제 시간에 한다.

## 규칙 2 — 위키 노트는 원자적으로
- 하나의 노트 = 하나의 개념. 제목만 보고 내용을 알 수 있게.
- 좋은 제목: `동행자-원칙`, `우울장애` / 나쁜 제목: `2026 메모`, `자료1`
- 길어지면 쪼갠다. 쪼개면 링크로 잇는다.

## 규칙 3 — 링크 없는 노트는 없다
새 위키 노트를 만들면 반드시:
1. 관련 노트로 가는 `[[링크]]` 2개 이상
2. 해당 영역 MOC에 한 줄 등록 ([[정품사역-v2]] / [[MOC-설교]] / [[MOC-목양]] / [[MOC-행정]])

링크할 곳이 없으면 → 아직 위키로 올릴 때가 아니다. 인박스에 둔다.

## 규칙 4 — 원자료는 건드리지 않는다
`20-원자료/`의 변환 파일은 참고용 원본. 수정·정리하지 않는다.
쓸 내용이 있으면 위키 노트로 **새로 써서** 원자료를 링크한다:

```markdown
출처: [[20-원자료/인박스/예수말씀의 전승궤도|예수말씀의 전승궤도 (원자료)]]
```

## 자주 하는 작업

| 하고 싶은 것 | 방법 |
|---|---|
| 설교 준비 시작 | 템플릿/설교 복사 → `10-위키/설교/`에 날짜-제목으로 |
| 상담 후 기록 | 템플릿/상담메모 복사 → MOC-목양에 등록 |
| 회의록 정리 | 템플릿/회의록 복사 → MOC-행정에 등록 |
| 설교 소재 찾기 | `#설교소재` 태그 검색 + [[MOC-설교]] 주제별 |
| 막막할 때 | [[홈]]으로 → 지금 하는 일 확인 |
