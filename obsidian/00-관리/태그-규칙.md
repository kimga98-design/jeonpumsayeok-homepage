# 태그 규칙

> 폴더가 말해주는 건 태그로 다시 말하지 않는다. 태그는 **폴더를 가로지르는 연결**에만 쓴다.

---

## 허용 태그 (이 목록이 전부)

### 도메인 (노트의 성격)
| 태그 | 용도 |
|---|---|
| `#MOC` | 지도 노트에만 |
| `#시스템` | 볼트 운용 문서 |
| `#설교` | 설교문 |
| `#목양` | 상담·심방 기록 |
| `#행정` | 회의·기획·운영 |

### 크로스 링크 (폴더 경계를 넘는 연결)
| 태그 | 용도 |
|---|---|
| `#설교소재` | 어느 폴더든 설교에 쓸 수 있는 내용 |
| `#위기` | 위기 대응 관련 — 급할 때 한 번에 검색 |
| `#핵심` | 사역 이해에 꼭 필요한 기본 노트 |

### 상태 (임시 — 처리되면 삭제)
| 태그 | 용도 |
|---|---|
| `#처리중` | 인박스에서 위키로 옮기는 중 |
| `#보류` | 판단 보류 |

---

## 금지 사항
- ❌ 새 태그 즉흥 생성 — 필요하면 이 문서에 먼저 추가하고 사용
- ❌ 폴더명 중복 태그 (`#원자료`, `#인박스`, `#위키`)
- ❌ 변환 파일 자동 태그 — 원자료엔 태그를 붙이지 않는다
- ❌ 태그 총 종류 15개 초과 — 넘으면 통합

## 왜 이렇게 하나
태그 하나에 수백 개 노트가 묶이면 그래프가 허브-스포크(바퀴살)가 되어
연결이 의미를 잃는다 (과거 `#inbox`, `#원자료` 사태).
태그는 적을수록 강하다.
