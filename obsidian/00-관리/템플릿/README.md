# 템플릿

새 노트는 여기서 복사해서 시작한다.

| 템플릿 | 저장 위치 | MOC 등록 |
|---|---|---|
| [[템플릿-설교]] | `10-위키/설교/` | [[MOC-설교]] |
| [[템플릿-위키노트]] | `10-위키/` 해당 폴더 | 해당 영역 MOC |
| [[템플릿-상담메모]] | `10-위키/목양/` | [[MOC-목양]] |
| [[템플릿-회의록]] | `10-위키/행정/` | [[MOC-행정]] |
| [[템플릿-주간리뷰]] | `30-일지/` | — |

**Obsidian 설정 → 코어 플러그인 → 템플릿** 켜고
템플릿 폴더를 `00-관리/템플릿`으로 지정하면 `Cmd+P → 템플릿 삽입`으로 바로 쓸 수 있다.
